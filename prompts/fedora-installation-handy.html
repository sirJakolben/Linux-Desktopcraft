Fedora 44 KDE installieren

Vorher

Noch unter Windows, bevor du neu startest.

  1. Der Fedora-Stick (General UDisk, 16 GB) steckt hinten direkt am Mainboard. Der erste Stick war defekt, nimm ihn nicht.

  2. Handy geladen, diese Seite offen. Das Monitorkabel steckt an der Grafikkarte, nicht an den Anschlüssen des Mainboards.

  3. Alle Programme schließen. Dann Start → Ein/Aus → Neu starten.

B1Vom Stick starten und ausprobieren

Hier wird noch nichts installiert. Du schaust nur, ob Bild, Maus, Tastatur und Internet unter Fedora funktionieren.

  1. Sobald der Bildschirm beim Neustart schwarz wird oder das Gigabyte-Logo erscheint: F12 immer wieder drücken, etwa einmal pro Sekunde.

    Startet doch Windows: noch einmal neu starten und früher mit F12 anfangen.

  2. Es erscheint das Boot-Menü des Mainboards. Wähle mit den Pfeiltasten den Eintrag mit UEFI und General UDisk im Namen, dann Enter.

    Nicht „Windows Boot Manager“, und nicht den Stick-Eintrag ohne „UEFI“, falls es zwei gibt.

  3. Jetzt kommt das Fedora-Startmenü (weiße Schrift auf Schwarz). Ausgewählt ist Test this media & start Fedora-…-Live. Lass es so und drück Enter.

    Dabei wird der Stick ein paar Minuten lang geprüft. Bei einem neuen Stick lohnt sich das.

  4. Der KDE-Desktop erscheint. Prüfe:

    • Bild scharf, Maus und Tastatur reagieren.
    • Internet: unten rechts auf das Netzwerk-Symbol tippen, notfalls WLAN wählen und Passwort eingeben.

    Bleibt der Bildschirm schwarz: Notfall → Schwarzer Bildschirm.

Tastatur im Live-System

Das Live-System hat vermutlich ein US-Tastaturlayout. Den Schrägstrich / brauchst du gleich mehrmals. Bei US-Layout liegt er auf deiner Taste - rechts neben dem Punkt. Y und Z sind vertauscht.

B2Installieren

Fedora kommt in die 500 GB, die du unter Windows freigemacht hast. Windows bleibt unangetastet.

Drei Regeln für diesen ganzen Abschnitt

1. Nicht Use entire disk nehmen. Das löscht Windows.

2. Auch nicht die Option, die Fedora neben ein anderes System in den freien Platz legt (etwa „Share disk“ oder „Use free space“). Sie würde die 100-MB-Startpartition von Windows mitbenutzen, und die ist zu klein.

3. Im Partitionseditor nur die Zeile Free space anfassen. Keine andere Zeile anklicken, löschen oder formatieren.

Installer starten

  1. Auf dem Desktop oder im Startmenü auf den Eintrag zum Installieren tippen (heißt etwa Install Fedora Linux oder „Install to Hard Drive“).

  2. Sprache: Ich empfehle English (United States). Dann stimmen die Knopfnamen auf dieser Seite genau. Deutsch stellst du nach der Installation in einer Minute um. Wenn du doch Deutsch wählst, such die passende Übersetzung der englischen Namen.

    Gibt es eine Tastatur-Einstellung, nimm German. Dann Next.

  3. Bildschirm Installation method: Unter Destination muss die WD_BLACK SN850X mit etwa 2 TB stehen. Nicht die Toshiba mit 1 TB, nicht der 16-GB-Stick. Sonst über Change destination wechseln.

    Bei den Optionen darunter nichts auswählen.

  4. Oben rechts auf die drei senkrechten Punkte ⋮ tippen → Launch storage editor.

    Es kommt eine Warnung, dass Änderungen im Editor sofort gelten. Noch einmal Launch storage editor.

Partitionen anlegen

So sieht deine SSD im Editor ungefähr aus. Größen können je nach Einheit etwas anders angezeigt werden (500 GiB = 537 GB).

ZeileGrößeWas tun
EFI (Windows)~100 MBnicht anfassen
Reserviert (Windows)~16 MBnicht anfassen
NTFS, das ist C:~1,4 TBnicht anfassen
Free space~500–537 GBhier arbeiten
Wiederherstellung (Windows)~1 GBnicht anfassen

  1. Linux-Startpartition (EFI): ⋮ neben Free space → Create partition.

    • Name: LINUX-EFI
    • Mount point: /boot/efi
    • Type: EFI system partition
    • Size: 1 GB
    • „Overwrite existing data with zeros“ nicht anhaken

    → Create

  2. Kernel-Partition: wieder ⋮ neben dem restlichen Free space → Create partition.

    • Name: boot
    • Mount point: /boot
    • Type: EXT4
    • Size: 2 GB

    → Create

  3. Hauptpartition: ⋮ neben dem restlichen Free space → Create partition.

    • Name: fedora
    • Mount point: leer lassen
    • Type: BTRFS
    • Size: den ganzen Rest (Regler ganz nach rechts)
    • Verschlüsselung: No encryption

    → Create

  4. Bereich für das System: Unter der neuen BTRFS-Partition steht top-level. ⋮ daneben → Create subvolume.

    • Name: root
    • Mount point: /

    → Create

  5. Bereich für deine Dateien: wieder ⋮ neben top-level → Create subvolume.

    • Name: home
    • Mount point: /home

    → Create

Warum die beiden Unterbereiche?

Ohne sie bricht Fedora 44 die Installation ab, mit der Meldung „Device … with mount point '/' not found in devicetree“ (Fedora-Fehler 2463653). Mit root und home klappt es, so wurde es im Fedora-Forum bestätigt.

  1. Kontrolle, bevor es weitergeht:

    • neu: 1 GB mit /boot/efi
    • neu: 2 GB mit /boot
    • neu: BTRFS mit root → / und home → /home
    • Die Windows-Zeilen sehen aus wie vorher.

    Passt etwas nicht: Foto machen und Notfall → Unsicher.

  2. Oben auf Return to installation. Der Installer prüft die Aufteilung. Meldet er einen Fehler, fehlt eine der Partitionen: Foto machen.

Abschließen

  1. Zurück auf Installation method ist jetzt die Option mit deiner eigenen Aufteilung ausgewählt (etwa Use configured storage oder Mount point assignment). Dort stehen /boot/efi, /boot, / und /home. Dann Next.

  2. Encrypt my data: nicht anhaken. Verschlüsselung ist in unserem Plan nicht vorgesehen. → Next

  3. Zusammenfassung lesen. Formatiert werden dürfen nur die drei neuen Partitionen (1 GB, 2 GB, ~497 GB).

Stopp, wenn eins davon zutrifft

• C: (NTFS, ~1,4 TB) oder eine andere Windows-Partition soll gelöscht oder formatiert werden.

• Die 100-MB-Startpartition von Windows soll formatiert werden. Fedora 44 zeigt das manchmal fälschlich an (Fehler 2436310), aber wir gehen kein Risiko ein.

• Auf dem Knopf steht Erase data and install.

Dann nicht installieren. Foto machen, Back, und siehe Notfall → Unsicher. Bis zu diesem Knopf ist an Windows nichts verändert.

  1. Alles in Ordnung: auf Install tippen. Das dauert etwa 5 bis 15 Minuten.

  2. Bei Successfully installed → Exit to live desktop. Dann Startmenü → Restart. Wenn der Bildschirm schwarz wird, Stick abziehen.

B3Erster Start

  1. Es erscheint das Fedora-Bootmenü mit zwei Einträgen: Fedora Linux … und Windows Boot Manager. Nach ein paar Sekunden startet Fedora von allein.

    Fehlt „Windows Boot Manager“: erst mal weitermachen, wir richten das in Phase C ein. Windows erreichst du bis dahin über F12.

  2. Ein Einrichtungsassistent (Plasma Setup) fragt nach Sprache, Tastatur und deinem Benutzerkonto. Jetzt Deutsch und Tastatur German wählen.

  3. Benutzerkonto: Benutzername klein und ohne Leerzeichen, zum Beispiel aaron. Gibt es eine Option „Administrator“, anhaken.

    Passwort aufschreiben. Du brauchst es ständig, auch wenn Claude später Programme installiert.

  4. Anmeldung testen: einmal abmelden und mit dem neuen Passwort wieder anmelden. Bei Fedora 44 gab es vereinzelt Berichte, dass man sich nach der Einrichtung nicht anmelden konnte. Klappt es nicht: Foto, Notfall → Unsicher.

  5. Windows prüfen: neu starten, im Fedora-Bootmenü mit den Pfeiltasten Windows Boot Manager wählen, Enter. Windows muss normal starten.

    Geht die Uhr unter Windows ein, zwei Stunden falsch, ist das normal. Das beheben wir in Schritt C4.

Geschafft

Phase B ist fertig. Weiter mit Danach.

Notfall

Schwarzer Bildschirm

Bleibt der Bildschirm nach dem Fedora-Startmenü länger als 2 Minuten schwarz oder friert ein:

  1. Einschaltknopf am PC 5 Sekunden gedrückt halten, bis er aus ist. Dadurch geht nichts kaputt, es ist ja noch nichts installiert.

  2. Wieder einschalten, F12, Stick wählen. Im Fedora-Startmenü mit den Pfeiltasten auf Troubleshooting, Enter, dann den Eintrag mit basic graphics mode.

    Das Bild ist dann gröber, aber für die Installation reicht es. Der richtige NVIDIA-Treiber kommt in Phase C.

Kommt auch dann kein Bild: Prüf, ob das Monitorkabel wirklich an der Grafikkarte steckt. Danach zurück zu Windows und Claude fragen.

F12 öffnet kein Menü

Neu starten und F12 schon ab dem Moment des Einschaltens drücken. Klappt es nie: mit Entf ins BIOS und dort die Startreihenfolge suchen. Hier lieber ein Foto machen und Claude fragen, statt etwas zu verstellen.

Unsicher oder Fehlermeldung

Foto vom Bildschirm machen. Dann entweder in der Claude-App auf dem Handy fragen (sag dazu: Dual Boot, Fedora 44 KDE, Windows 11 auf derselben SSD, eigene EFI-Partition für Linux) oder abbrechen und unter Windows mit Claude weitermachen. Bis du auf Install tippst, ist an Windows nichts verändert. Angelegte Linux-Partitionen im freien Bereich stören Windows nicht.

Danach: C0 unter Fedora

Claude unter Linux installieren und dort weitermachen.

  1. Im Startmenü Konsole öffnen. Das ist das Terminal von KDE.

  2. Claude Code installieren:

    curl -fsSL https://claude.ai/install.sh | bash

    Danach ein neues Konsole-Fenster öffnen und prüfen. Es muss eine Versionsnummer erscheinen:

    claude --version

  3. Projekt holen:

    git clone https://github.com/sirJakolben/Linux-Desktopcraft.git

    Meldet die Konsole, dass git fehlt: sudo dnf install git eingeben, dein Passwort eintippen (man sieht dabei keine Zeichen), dann noch einmal klonen.

  4. In den Ordner wechseln und Claude starten. Beim ersten Mal meldest du dich im Browser an:

    cd Linux-Desktopcraft && claude

  5. Claude diesen Satz schreiben:

    Lies prompts/linux-umzug-begleiter.md und folge den Anweisungen darin. Phase B ist erledigt, wir machen mit C1 weiter.
